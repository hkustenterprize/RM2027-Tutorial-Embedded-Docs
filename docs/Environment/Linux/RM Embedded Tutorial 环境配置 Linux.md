# RM Embedded Tutorial：Linux 环境配置 - Linux

请根据所使用的 Linux 发行版，自行搜索并安装以下组件：

- Git
- GitHub CLI（`gh`）
- GNU Make（`make`）
- CMake
- Ninja
- Arm GNU Toolchain（`arm-none-eabi-gcc`、`arm-none-eabi-g++`）
- Visual Studio Code
- STM32CubeMX
- SEGGER J-Link Software and Documentation Pack
- SEGGER Ozone
- SEGGER SystemView

安装过程中如遇到问题，请联系我们。
